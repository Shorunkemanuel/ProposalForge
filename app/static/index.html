AI provider setup

ProposalForge drafts proposals with a compatible API. The usual setup is a hosted endpoint: choose a provider preset (or a custom compatible endpoint), enter a model identifier, and your own API key (BYOK). Each provider expects the key issued by that provider; a key from one provider does not work with another. No account is created here and the key is kept in memory only. Running your own local inference server is also supported if you prefer local processing.

Model availability, quotas, and any charges depend on your provider account and the model you choose. ProposalForge does not ask for, or assume, whether a key is free or paid.

First-time setup

  1. Choose a provider preset (its documented base URL is filled in).
  2. Enter the model identifier to use, or refresh models to pick one from what the endpoint offers.
  3. If the endpoint is hosted, enter the API key issued by that provider.
  4. Test the connection to verify the endpoint is reachable. It uses the values above, even before saving.
  5. Save the settings to apply them to this running server now; unsaved provider changes are also applied automatically when you generate a draft.

Settings apply to this running server only. They are held in memory and reset when it stops; nothing is saved to disk or an account.
